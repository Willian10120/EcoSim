# Eco-Simulador

Simulador web que mostra como escolhas sustentáveis mudam uma cidade. O usuário ativa arborização, mobilidade sustentável e energia limpa e vê na hora o efeito na paisagem e na qualidade do ar.

## ODS
ODS 11 – Cidades e Comunidades Sustentáveis (meta 11.6)

## Como acessar
Abra o arquivo index.html no navegador
